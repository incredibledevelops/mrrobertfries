## 🎯 Week 2 — The three things your client will ask for

After the first real orders roll in, these three always come up:

### 1. **WhatsApp notifications** (his #1 ask — guaranteed)
Every Ghanaian customer prefers WhatsApp. When an order is placed, paid, dispatched, and delivered, they should get a WhatsApp message — not just SMS.

**Effort:** 4 hours. **Impact:** Customers stop calling to ask "where is my food?".

### 2. **Refunds & cancellations** (his #2 ask)
Someone orders wrong, or a rider can't deliver. He needs to cancel and refund from the admin panel — without opening Paystack.

**Effort:** 2–3 hours. **Impact:** Protects him from disputes and lost money.

### 3. **Order scheduling** ("deliver at 7pm tonight")
"Can I place this order now but have it delivered at 7?" He'll ask. Corporate lunch orders are the biggest single-ticket customers.

**Effort:** 3 hours. **Impact:** Opens up corporate / bulk orders.

## 🚨 Common deploy-week fires and how to avoid them

| Fire | Prevention |
|---|---|
| **Paystack webhooks fail silently** | Test the webhook URL with Paystack's test dashboard before going live. Check Render logs for `/payments/webhook` hits. |
| **Uploaded images vanish on redeploy** | That's why you need Cloudinary. Do this BEFORE the first real image is uploaded. |
| **Arkesel Sender ID rejected** | Ghana NCA takes 1–3 days. Submit the Sender ID application **today**, not the day you deploy. |
| **MongoDB Atlas network access too open** | Whitelist only Render's IPs. `0.0.0.0/0` is a security hole. |
| **Admin password still `Admin@1234`** | Change it before you give him the URL. He'll share it. |
| **Paystack test card accidentally left in prod** | Set `PAYSTACK_SECRET_KEY=sk_live_...` and `NEXT_PUBLIC_PAYSTACK_PUBLIC_KEY=pk_live_...` |
| **CORS errors on the live domain** | Set `CORS_ORIGINS=https://mrfries.com,https://www.mrfries.com` (with `www` too) |
| **Frontend points at localhost** | Set `NEXT_PUBLIC_API_URL=https://api.mrfries.com` |
| **Emails go to spam** | Verify the domain on Resend. Add SPF / DKIM / DMARC records. |
| **`DEBUG=True` in prod** | Leaks stack traces. Set `DEBUG=False`. |
